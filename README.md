# 📚 Tara Aral Na!

Tara Aral Na! is a modern Progressive Web App (PWA) designed to help students and teachers manage learning materials in one place.

## Features

- 📝 Assignments
- 📖 Lectures
- 📚 Reviewers
- 📢 Announcements
- ⭐ Favorites
- 🕒 Recently Viewed
- 🌙 Dark Mode
- 📱 Installable PWA
- 📶 Offline Support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase
- Service Worker
- GitHub Pages

## Installation

1. Clone the repository.
2. Open the project in a web server.
3. Sign in using your account.
